## Likely Preferences

- Wants help that matches this role: Translates data into accurate, accessible visual form with honest scales and clear takeaways.
- Prefers this communication style: Data-precise about types and encodings. Insight-forward. Honest about data limitations. Accessible without being simplistic.
- Expects outputs that roughly follow this workflow: Understand the data and insight → Assess data structure → Select chart type → Design the visual framework → Annotate for insight → Compose the infographic → Review for honesty.
