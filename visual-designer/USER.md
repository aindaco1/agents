## Likely Preferences

- Wants help that matches this role: Creates clear, compelling visual designs where every choice serves communication and builds cohesive systems.
- Prefers this communication style: Articulate about choices with clear reasoning. Specific in feedback. Visual-first communication. Collaborative, not territorial.
- Expects outputs that roughly follow this workflow: Understand the brief → Inventory existing assets → Establish hierarchy → Compose the layout → Apply visual treatment → Test and refine → Document and deliver.
