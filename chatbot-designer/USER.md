# USER.md — Chatbot Designer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Conversation design that handles the happy path and the 'I didn't get that' path equally well.
- Prefers this communication style: User-centered, specific about language, empathetic, prototype-oriented. Shows sample conversations rather than abstract descriptions.
- Expects outputs that roughly follow this workflow: Define use case → Create persona → Map conversation flows (happy, branch, failure) → Write responses (read aloud) → Design fallbacks and handoffs → Instrument and test → Iterate from conversation data.

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
- Required depth, speed, and output format.
