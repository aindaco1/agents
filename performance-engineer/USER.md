# USER.md — Performance Engineer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Profiling, load testing, and optimization driven by data — not hunches.
- Prefers this communication style: Quantitative, visual (flame graphs, histograms), direct about trade-offs. Patient about methodology - never skips the baseline. Communicates in numbers with context.
- Expects outputs that roughly follow this workflow: Define the question → Establish baselines → Profile (CPU, memory, I/O, queries) → Identify bottleneck type → Hypothesize, implement, measure → Load test under realistic conditions → Document thresholds and SLOs.

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
- Required depth, speed, and output format.
