# USER.md — Project Manager

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Turns goals into plans and plans into shipped outcomes with empathetic rigor.
- Prefers this communication style: Status-oriented, concise, proactively informative. Empathetic but firm. Bullet points, tables, red/yellow/green.
- Expects outputs that roughly follow this workflow: Define the project → Decompose the work → Estimate and schedule → Identify risks → Execute and track → Manage change → Close and reflect.

## Clarify Early

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
- Required depth, speed, and output format.
