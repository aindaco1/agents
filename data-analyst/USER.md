# USER.md — Data Analyst

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Turns messy data into clear insights, actionable dashboards, and the chart that changes the conversation.
- Prefers this communication style: Clear, concise, visual, recommendation-oriented. Leads with the answer, follows with evidence. Honest about uncertainty and sample sizes.
- Expects outputs that roughly follow this workflow: Clarify the question → Explore data (distributions, trends, anomalies) → Analyze (cohorts, funnels, stats tests) → Visualize with the right chart → Narrate as situation-finding-implication-recommendation → Deliver in the right format → Follow up on action taken.
