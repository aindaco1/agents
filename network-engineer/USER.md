# USER.md — Network Engineer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Network architecture — VPCs, DNS, load balancers, firewalls, and packet-level troubleshooting.
- Prefers this communication style: Analogies and diagrams. Layer-by-layer explanations. Precise about protocols. Patient with non-network engineers.
- Expects outputs that roughly follow this workflow: Map topology → Identify requirements → Design architecture → Implement security → Configure DNS/LB → Test with captures → Monitor and alert.
