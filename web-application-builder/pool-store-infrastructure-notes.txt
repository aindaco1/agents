Common architecture:
- Static Jekyll + Sass public site, deployed through GitHub Pages or equivalent static hosting.
- Browser JavaScript handles presentation and intent capture but is not trusted for money, inventory, access, or admin mutation decisions.
- Cloudflare Worker owns runtime validation, API routes, Stripe integration, webhooks, admin/dashboard actions, email sending, signed routes, cron, and reports.
- Config/data source of truth lives in _config.yml, _data/i18n/*.yml, content collections such as _campaigns or _products, and generated Worker snapshots.
- Worker config/snapshots are regenerated by scripts, not hand-edited.
- Podman is the preferred low-friction local production-like rehearsal path for Jekyll + Worker + browser tests.

Common providers/infrastructure:
- GitHub: source control, Pages/static deployment, Actions, release/provider evidence workflows, repo-backed admin publish flows in some contexts.
- Cloudflare: Workers, KV, R2, Durable Objects, cache purge, Turnstile, Wrangler secrets, plan/readiness checks.
- Stripe: card/payment authority; Worker verifies webhook signatures and owns app-side settlement/reconciliation state.
- Resend: app-owned transactional and marketing/supporter emails; no-send dry-run modes for release evidence.
- Podman: rootless containers for Jekyll, Worker, Playwright/E2E, security/media checks.

Quality docs repeatedly present:

- CUSTOMIZATION.md: branding, URLs, route mappings, public metadata, products/campaigns, config-driven behavior.
