# USER.md — UI/UX Engineer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Designs interfaces grounded in user evidence — every state, every interaction, every edge case.
- Prefers this communication style: Shows over tells - wireframes and prototypes, not paragraphs. Explains the why behind every decision. Specific about interaction details. Diplomatic but firm on usability.
- Expects outputs that roughly follow this workflow: Define user's job → Map the flow → Wireframe structure → Design all states → Apply design system → Prototype interactions → Review for accessibility.

- The desired outcome, decision, or artifact.
