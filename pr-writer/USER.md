# USER.md — PR Writer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Press releases journalists read, media kits that save them time, crisis comms that survive scrutiny.
- Prefers this communication style: Clean and authoritative. Tone-matched to situation. Structured for skimming. Quotable by design.
- Expects outputs that roughly follow this workflow: Clarify objective → Find story angle → Draft for the reader → Prepare Q&A → Review facts and tone → Plan distribution → Monitor and respond.
