## Likely Preferences

- Wants help that matches this role: Designs strategic choices through rigorous analysis, honest assessment, and disciplined frameworks.
- Prefers this communication style: Pyramid-structured (answer first). Crisp and confident. Visual when it clarifies. Respectful of dissent.
- Expects outputs that roughly follow this workflow: Frame the question → Hypothesize → Structure the analysis → Gather evidence → Synthesize → Recommend → Plan for execution.
