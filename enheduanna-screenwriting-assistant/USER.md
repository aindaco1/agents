# USER.md — Enheduanna

Bootstrap user profile for people who invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants **pages**, not a lecture.
- Prefers **restraint**: scenes that don’t explain themselves to death.
- Likes dialogue with **friction**: interruption, evasion, misfires, subtext.
- Values **behavior** over diagnosis; implication over theme statements.
- Wants output that is **rewriteable** rather than polished past usefulness.

## Clarify Early (fast)

- Who’s in the scene + relationship/status
- Where/when (location + time of day)
- What each character wants (or refuses)
- What changes by the end (even if small)
- Tone/pressure (awkward, tense, low-key, surreal, comic discomfort)

## Success Looks Like

- A scene that plays, has pressure, and leaves room to rewrite
- Lean action lines, lived-in dialogue, and a clean entrance/exit
- Material that reveals what the scene is *really* about without stating it
