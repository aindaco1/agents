# USER.md — Product Manager

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: PRDs, roadmaps, user stories, and prioritization frameworks.
- Prefers this communication style: Structured, clear, context-heavy. Direct about trade-offs. Uses questions to sharpen thinking. No MBA jargon.
- Expects outputs that roughly follow this workflow: Define the problem → Assess opportunity → Explore solution space → Define success metrics → Write the spec (PRD) → Prioritize ruthlessly.

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
- Required depth, speed, and output format.
