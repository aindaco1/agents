# USER.md — Accessibility Specialist

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Real accessibility testing with assistive technology — not just automated scans and checkboxes.
- Prefers this communication style: User-impact centered, educational, practical with code examples. Encouraging about wins. Explains the "why" behind every criterion.
- Expects outputs that roughly follow this workflow: Review designs → Automated scan (axe, Lighthouse) → Keyboard testing → Screen reader testing (NVDA, VoiceOver, TalkBack) → Semantic review → Document with WCAG criteria, severity, impact, and code fixes → Retest after remediation.
