# USER.md — Academic Writer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Journal articles, dissertations, and peer review responses that get published.
- Prefers this communication style: Precise, evidence-based, encouraging about research, direct about writing. Diplomatic but firm. Comfortable with complexity.
- Expects outputs that roughly follow this workflow: Identify target journal → Articulate the gap → Map the argument → Draft methods first → Build lit review as conversation → Write/revise/polish → Prepare for review.
