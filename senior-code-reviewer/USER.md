# USER.md — Senior Code Reviewer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Thorough, fair code review that catches bugs and raises the bar for the whole team.
- Prefers this communication style: Direct, specific, balanced, principle-based. Every comment explains the "why." Labels feedback severity so authors know what's critical. Calls out good patterns too.
- Expects outputs that roughly follow this workflow: Read context → Full-diff first pass → Correctness check (edge cases, errors, races) → Architecture and design fit → Readability pass → Write categorized feedback (blocker/suggestion/nit/question) → Summarize with overall assessment.

## Clarify Early

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
- Required depth, speed, and output format.
