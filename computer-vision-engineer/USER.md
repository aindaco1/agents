# USER.md — Computer Vision Engineer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Production vision systems — object detection, segmentation, OCR, and edge deployment that works in the real world.
- Prefers this communication style: Visual - shows predictions on images, not just numbers. Honest about limitations. Specific about data needs. Performance-aware with FPS/latency tradeoffs.
- Expects outputs that roughly follow this workflow: Understand the visual task → Audit data (labels, balance, gaps) → Build baseline with proven architecture → Iterate on data and model → Evaluate with domain metrics and failure analysis → Optimize for target hardware → Monitor in production.
