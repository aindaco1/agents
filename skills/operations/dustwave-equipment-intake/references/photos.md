# Faithful equipment photography

The owner's desired result is tightly framed equipment imagery, often on white,
with identifying labels and included components visible. The purpose is inventory
evidence, not idealized product advertising.

1. Inspect the originals before editing. Keep originals separate and unchanged.
2. Prefer a deterministic rectangular crop with a modest margin. Remove unrelated
   surroundings without clipping the equipment, cables, mounting pins, or feet.
3. Background masking is optional when available through a permitted tool and it
   preserves original subject pixels. A little floor is better than reconstructed
   hardware. Do not invent areas hidden by a hand or cropped out of the original.
4. Do not use generative reconstruction, relighting, sharpening that fabricates
   lettering, or product renders as factual inventory photographs. Some earlier
   edits in the source conversation used generative cutouts; do not reproduce
   that method when it changes labels, perspective, condition, or geometry.
5. Compare each result with its source: labels/serials, screw and port counts,
   leg geometry, accessory counts, condition, holes, cable routing, and empty
   case slots. If altered, reject that output and use a faithful crop/original.
6. Upload cleanly named files directly to Notion, one image per block, captioned
   with supported facts. Multiple views of one item are not multiple inventory units.

Use only image-editing tools permitted by the current host. This reference grants
no exception to host tool restrictions. If the available tool cannot preserve the
source faithfully, retain the original and explain the limitation in chat instead
of silently substituting invented detail.

## Estimates

Only estimate dimensions when asked. Use a short range and state which dimension
it describes, what visual scale it uses, and that it is approximate. Account for
perspective. A shoe without known dimensions is a weak reference. If the item is
packed, estimate the visible packed case only; do not infer opened dimensions
from an assumed folding ratio. Do not change between incompatible estimates
without explaining the revision. Keep estimates out of the title unless useful
and explicitly marked approximate.

## Manuals

If requested, prefer an exact manufacturer-hosted PDF. Check the cover/model and
revision before attaching it. A successful download must be a real PDF rather
than an HTML error/login page. Upload/embed the PDF and retain a source link;
do not rely solely on a fragile remote embed. A manual naming multiple models
does not prove that every listed component is physically in the kit.
