# Compact evidence records

Use these fields inside the project's existing notes, spreadsheet, reference manager, or manuscript comments. Scale the record to the task; do not create empty administrative files for a short edit.

## Source record

| Field | Record |
|---|---|
| Source key | Stable manuscript citation key |
| Identity | Verified title, authors, year, venue/publisher, DOI or stable identifier |
| Version/status | Exact version, preprint/publication status, correction or retraction check and date |
| Access | Full text / abstract / metadata / unavailable; location of inspected copy |
| Relevant evidence | Passage, page, table, figure, archival locator, or result supporting the claim |
| Limits | Design, population, assumptions, uncertainty, conflicts, counterevidence |

Keep citation keys stable while editing prose. Preserve exact quotations separately from paraphrase and retain translation attribution. A search snippet is a discovery lead, not a substitute for the cited passage.

## Claim record

| Claim ID / manuscript location | Bounded claim | Source key + locator or result artifact | Evidence status | Limitation / next action |
|---|---|---|---|---|
| C1 / Results paragraph 2 | Exact population, outcome and comparison | Existing table, analysis output, or source locator | Verified / author-supplied / needs verification / unsupported | Missing provenance or narrowed interpretation |

The example row describes fields; it is not a research result. Remove illustrative rows before using a record as evidence.

## Result provenance

For each central result, preserve the input dataset/document version, selection and exclusion decisions, analysis or proof source, software/environment if used, command/configuration, execution date, output file, and checks actually performed. Link figures and tables to those outputs. Record failed runs and deviations when they affect interpretation. Keep restricted raw data in its authorized location and provide an appropriate access statement.

## AI-use record and disclosure

Record tool/system, model/version if known (otherwise say unknown), date, purpose, affected sections/code/figures, retained outputs, and human verification. Distinguish search assistance, translation/copyediting, generated prose, code, analysis, and images.

Disclosure scaffold, to complete with true facts and adapt to the venue:

> During [stage], the authors used [tool and known version] for [specific task] affecting [sections/assets]. [Describe verification and author responsibility accurately.]

Do not paste unresolved bracketed fields into a final submission or assert human review before it occurs. Keep the record even if the venue exempts a particular editing use from public disclosure.

## Completion note

State the manuscript status, unresolved claim/source issues, bibliography checks, reproduced versus supplied results, figure/PDF inspection, humanizer pass, and disclosure policy checked. Report only checks actually performed. This should usually be a short handoff, not a ceremonial checklist appended to the paper.
