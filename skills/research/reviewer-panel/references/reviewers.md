# Reviewer directory

Use the role ID or plain-language name to select a lens. The profile column names its canonical roster owner in both runtimes.

| Role ID | Reviewer | Existing profile | Decision to test |
|---|---|---|---|
| `acquisitions-editor` | Commissioning editor | `content-strategist` | Would you commission this for the named list or publication? Identify the promise, its audience, a comparable work, and the page that delivers or loses the pitch. |
| `cultural-critic` | Cultural critic | `trend-analyst` | What familiar event does the piece help someone see differently? Test its strongest example against a competing cultural explanation and say where the analogy stops working. |
| `policy-intellectual` | Policy reviewer | `research-analyst` | Name the implementing institution, decision authority, affected group and assumption joining the proposal to its intended result. Identify evidence that would distinguish it from a plausible alternative. |
| `bookshop-browser` | Bookshop browser | `reading-list-curator` | Read only the visible title, subtitle and jacket first. State what book you expect to find inside and whether you would open it. Then compare that expectation with the actual premise. |
| `incumbent-adversary` | Incumbent competitor | `competitive-intelligence-analyst` | Identify the cheapest credible response available to an incumbent and the constraint that might prevent it. Label any competitor capability the evidence does not establish. |
| `vc-stress-tester` | Venture investor | `startup-pitch-stress-tester` | Use the existing pitch rubric. Identify the assumption that carries the return case and the observation that would invalidate it. Test an actual unit or cohort if figures are supplied. |
| `enterprise-buyer` | Enterprise buyer | `market-researcher` | Trace the path from the stated pain to a budget owner, approval, switching cost and credible next step. Include the option to keep the current solution. |
| `impatient-subscriber` | Impatient subscriber | `newsletter-writer` | Read the subject, preview and opening as a subscriber with limited time. Mark the first line where opening or continuing stops feeling worthwhile and what payoff the issue actually delivers. |
| `contrarian-reader` | Contrarian reader | `editor` | Reconstruct the author's strongest argument. Identify one counterexample that changes its conclusion, or explain why the strongest objection only narrows its scope. |
| `sales-leader` | Sales leader | `sales-strategist` | Can a manager assign accounts and coach a consistent next step? Try an ambiguous account against the proposed segment boundaries and identify a conflict in coverage. |
| `revenue-ops-analyst` | Revenue operations analyst | `sales-revenue-generalist` | Trace the segment or funnel rule into a field, source, denominator and owner. Test an account that matches twice or has missing data and explain the reporting effect. |
| `field-rep` | Field account executive | `sales-strategist` | Pick the next account and action using only information a rep would have before the call. Flag a rule that depends on hindsight and the smallest useful discovery question. |
| `creative-director` | Campaign creative director | `design-director` | Identify the creative idea in one sentence. Test whether it survives a change of format, which execution makes it distinctive, and what a competent generic campaign could also claim. |
| `brand-strategist` | Brand strategist | `product-marketing-manager` | Tie the proposed promise to a demonstrable brand or product truth. Apply the same line to a competitor and identify the words, proof or audience context that changes its meaning. |
| `target-consumer` | Target audience member | `market-researcher` | Use the audience and channel in the brief. Describe the likely interpretation, a plausible alternative, and the uncertain assumption a real audience test should resolve. |
| `grant-reviewer` | Grant reviewer | `grant-writer` | Apply the funder's published criteria when available. Separate eligibility, strength of the proposed work, and feasibility of the budget. Cite the passage that changes the funding recommendation. |
| `peer-reviewer` | Academic peer reviewer | `academic-researcher` | Identify the contribution and strongest competing explanation. Match the claim to the design, evidence and scope. State which criticism requires new work and which needs clearer reporting. |
| `skeptical-board-member` | Skeptical board member | `strategy-consultant` | Identify the decision being authorized, who owns it, the downside if a key assumption fails, and a milestone at which the board could reconsider. |
| `quant-analyst` | Quantitative analyst | `financial-analyst` | Rebuild a consequential figure with its units, denominator and time window. Vary the assumption nearest the decision boundary and show when the recommendation changes. |
| `lay-intelligent-reader` | Interested general reader | `technical-writer` | Read without specialist background. Restate the takeaway and point to the first unexplained term or inferential jump. Check the restatement against the author's actual claim. |

## Choosing perspectives

- For an essay, try a cultural critic and an impatient subscriber. Add a contrarian reader when the conclusion turns on a disputed premise.
- For a film-funding proposal, a grant reviewer can assess fit, the quantitative analyst can examine the budget, and the policy reviewer can test how the program would work.
- For sales segmentation, compare the manager allocating accounts, the rep using the rule, and the operations analyst measuring its effect. The first two are distinct reading tasks owned by the Sales Strategist.
- For a pitch, compare the investor's return case with the buyer's adoption barrier. Add the incumbent perspective when the advantage depends on competitors standing still.
