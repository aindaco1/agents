# Reviewer panel

Use a single named reviewer when requested. For a panel, start from the decision
the user faces and select two or three complementary roles from the
[reviewer directory](references/reviewers.md). Each row names the existing
specialist who owns that perspective. A direct request to that specialist uses
the same method. Choose among roles that belong to one specialist according
to the requested decision. Two views from one person are two perspectives.

Give every reviewer the same draft, audience, constraints and decision.
A cold reader sees only what the eventual reader sees on the first pass.
Record their takeaway before revealing the author's intended argument. A
funding or policy reviewer needs the actual call or proposal terms when available.
If a missing fact changes the verdict, identify it and make the verdict conditional.

For each role, return the decision in its own terms, the passage or number
that drove it, the most consequential objection, and what could change the
judgment. Show an effective passage worth preserving when there is one.
Use exact excerpts for text and recompute important arithmetic from stated
inputs. Identify simulated audience reactions. Cite real respondents only from
supplied or verified evidence. One model can apply several perspectives in a
single pass. Describe independence only when separate evaluations actually ran.

Close with the disagreement that would lead to different edits or decisions.
Recommend the smallest revision, source check or audience test that would
resolve it. Preserve the original wording for a critique-only request.
If all reviewers agree, identify the reason and any untested assumption.
For measured comparisons of offers use the existing buyer-panel-simulation
procedure. For manuscript drafting and formal responses use research-paper-authoring.

## Example

A proposal promises 50 screenings, while the attached budget funds 20. The
quantitative reviewer checks whether the other 30 have a funding assumption.
The grant reviewer checks whether 50 is a contractual deliverable. A first-time
reader may reasonably take all 50 as guaranteed. Resolve that disagreement by
asking which screenings are committed and matching the promise to the budget.
