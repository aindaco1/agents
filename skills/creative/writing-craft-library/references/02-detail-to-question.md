# Let an observed detail open a question

Use when: An essay begins with an abstract thesis but already contains an observation that motivates it.

Observed move: Leonard's airport signs prompt a question for which he does not yet have an answer. Williams establishes a child's skepticism through particular behavior before revealing why belief matters to her. The detail changes what the reader wants to know.

Apply it: Choose an existing detail that creates the actual question. Keep the connection modest until the supplied evidence supports a larger claim. The writer's attention supplies the movement.

Limits: Do not invent a room, object, overheard remark, or childhood memory to furnish an opening. Operational instructions often work better with the action first.
