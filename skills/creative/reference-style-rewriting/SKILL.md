# Reference-style rewriting

Use this when a user wants a draft rewritten in the style of a specific essay, outlet, or writer.

## Goal

Produce an original rewrite that borrows high-level traits:
- argumentative posture
- pacing
- paragraph length
- sentence rhythm
- framing moves
- level of abstraction
- use of irony or confidence

Do not imitate distinctive phrasing, structure, or verbal tics too closely.

## Finding and reading the reference

Read the user's source draft first. Use an available fetch or browser tool to
read the reference, then verify its title, byline, opening and article boundary.
For an accessible archived copy, retain its original URL and capture timestamp.
Exclude navigation, reader comments, advertisements and adjoining articles.

If access fails, try an authorized public copy or ask for the user's excerpt.
Do not bypass a paywall or access restriction. A partial extract can support
limited observations about the visible opening and paragraphs; state that limit
and do not infer the whole article's structure or ending from a search snippet.

When the brief needs examples rather than one exact reference, use
`writing-craft-library`. Load its index and at most two relevant technique cards.
The user's own voice sample remains the primary calibration source. Reference
articles supply compositional techniques, never new facts for the user's draft.

## Working method

1. Read the draft in full.
2. Read whatever reference text is accessible.
3. Write a short style diagnosis before rewriting. Name:
   - how the piece opens
   - how fast it reaches the argument
   - whether it starts concrete or abstract
   - typical paragraph size
   - how it handles contrast, escalation, and conclusion
   - what to avoid
4. If the style diagnosis is subtle or the match matters, compare two plausible diagnoses against the actual passages. Delegate a separate style analysis only when the user or applicable task instructions authorize agent delegation.
5. Rewrite from the diagnosis, not by shadowing the source line by line.

## Good output shape

For an argumentative essay whose brief calls for a sharper political-magazine
mode, these moves can help. They are not a default structure for memoir, lyrical
essays, reviews, or a source whose approved structure must remain:
- open with the conflict or political problem, not biography
- state the real claim early
- compress memoir into proof, not atmosphere
- use concrete examples before abstract claims
- cut feature lists and resume material
- end with a harder claim or challenge, not uplift

## Safety and quality rules

- Never copy memorable phrases from the reference unless the user explicitly asked for quotation.
- Avoid reproducing the exact structure of the source article.
- If the user asks for "more in the style of" a living writer or a single copyrighted article, translate that into high-level traits only.
- Be explicit internally about the distinction between inspiration and imitation.

## Useful diagnostic questions

Before rewriting, answer these in notes:
- What is the enemy or problem in this piece?
- By what paragraph does the real argument appear?
- What should be cut, compressed, or moved up?
- What autobiographical material is actually doing work?
- What is the sharper framing of the project, object, or thesis?

## Deliverables that help

Often save two things:
1. the rewritten draft
2. a short rewrite plan memo listing:
   - thesis
   - section order
   - what to cut
   - what to foreground
   - tonal rules

This is useful when the user wants a second pass later.

When the user explicitly approves the substance but rejects the style, preserve the approved content and treat the next pass as style-only. Do not reopen the argument or restructure the piece unless the user asks. Save each major stylistic pass as a separate version so the user can compare intensities instead of losing a draft they already liked.

For requests like "more humorous," "more irreverent," or "push this further," escalate in layers:
- keep the paragraph logic and core claims stable
- intensify metaphor density, ridicule, rhythm, and comic contrast
- keep the political and factual spine intact
- stop before the prose becomes self-amused to the point of breaking the argument

## Example lessons from use

For a rewrite of The Pool essay toward a sharper political-magazine mode, the effective moves were:
- foreground platform dependence as the antagonist
- frame tool-building as political self-defense
- treat existing crowdfunding limits as structural, not annoying
- present the platform as civic/scene infrastructure, not a startup product
- redefine DIY as collective capacity rather than individual hustle

## Pitfalls

- starting too softly with childhood wonder or personal origin story
- overexplaining chronology
- listing product features instead of making an argument
- becoming purple, academic, or slogan-heavy
- treating the reference style as a voiceprint to mimic instead of a set of compositional moves
