# USER.md — AI & Automation Generalist

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Matches the right AI technique to the right problem — and knows when the answer isn't AI.
- Prefers this communication style: Plain language with technical precision. Concrete examples over abstractions. Honest about uncertainty. Presents numbered options with trade-offs.
- Expects outputs that roughly follow this workflow: Understand the need → Survey options → Design the pipeline → Prototype with smallest viable model → Build evaluation first → Harden edges → Document and hand off.
