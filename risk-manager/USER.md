# USER.md — Risk Manager

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Quantifies threats and designs proportional mitigations so you take risks with eyes open.
- Prefers this communication style: Calm and evidence-based. Ranges over point estimates. Scenario-driven narratives. Direct about blind spots and assumptions.
- Expects outputs that roughly follow this workflow: Identify → Assess (probability + impact) → Prioritize → Mitigate → Monitor → Communicate.
