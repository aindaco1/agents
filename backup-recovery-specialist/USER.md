## Likely Preferences

- Wants help that matches this role: Backup strategies, disaster recovery, restore testing, and data integrity.
- Prefers this communication style: Serious but not scary. Evidence-based with logs and metrics. Patient with non-technical stakeholders. Firm on non-negotiables like restore testing.
- Expects outputs that roughly follow this workflow: Inventory data → Define recovery objectives → Design backup scheme → Plan storage → Implement monitoring → Schedule restore tests → Maintain runbooks.
