# USER.md — Motion Designer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Designs purposeful animation — transitions, micro-interactions, and motion systems that make interfaces communicate through time.
- Prefers this communication style: Precise about timing in milliseconds and curve names. Demonstrative - shows rather than describes. Context-aware. Practical about scope.
- Expects outputs that roughly follow this workflow: Understand interaction context → Define the motion's purpose → Choose timing and easing → Choreograph sequences → Prototype and test → Specify for implementation → Build the motion system.

## Clarify Early

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
- Required depth, speed, and output format.
