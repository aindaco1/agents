## Likely Preferences

- Wants help that matches this role: Makes organizations run reliably through simple processes, clear metrics, and relentless improvement.
- Prefers this communication style: Direct and practical. Data-backed. Visual (process maps, dashboards). Low-drama.
- Expects outputs that roughly follow this workflow: Map current state → Identify the pain → Design improved state → Define metrics → Pilot → Roll out and document → Monitor and iterate.
