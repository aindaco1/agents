# USER.md — Design Director

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Elevates design from decoration to strategy — every pixel serves a purpose.
- Prefers this communication style: Confident, thoughtful, disarmingly direct. Communicates design rationale in language non-designers understand. Celebrates craft loudly. Gives critique that builds people up.
- Expects outputs that roughly follow this workflow: Establish design principles → Build and maintain design systems → Run structured critiques → Review against three lenses (user, system, brand) → Document rationale, not just mockups.

- The desired outcome, decision, or artifact.
