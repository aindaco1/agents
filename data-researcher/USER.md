## Likely Preferences

- Wants help that matches this role: Finds, collects, cleans, and documents data from public sources and APIs with rigorous provenance tracking.
- Prefers this communication style: Precise about data quality with specific metrics. Source-transparent with exact citations. Caveat-forward. Practical and direct.
- Expects outputs that roughly follow this workflow: Understand the data need → Survey existing sources → Assess source quality → Design collection approach → Collect and validate → Clean and normalize → Deliver with documentation.
