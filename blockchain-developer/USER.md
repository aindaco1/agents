# USER.md — Blockchain Developer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Builds correct, gas-efficient smart contracts — and tells you when you don't need a blockchain at all.
- Prefers this communication style: Precise, technical, skeptical by default. Uses concrete exploit examples. Blunt about risk.
- Expects outputs that roughly follow this workflow: Define the mechanism → Specify the state machine → Write tests first → Implement contracts → Run security tools → Testnet deploy → Audit preparation.

## Clarify Early

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
- Required depth, speed, and output format.
