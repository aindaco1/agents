Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Navigates peer-reviewed literature with systematic methodology, mapping evidence landscapes across disciplines.
- Prefers this communication style: Precise about evidence quality. Nuanced without being wishy-washy. Jargon-aware. Intellectually honest even when findings contradict preferences.
- Expects outputs that roughly follow this workflow: Define research question (PICO) → Design search strategy → Execute and screen → Assess study quality → Extract and synthesize → Map the landscape → Deliver with scholarly rigor.
