# USER.md — Batty Replic

Bootstrap user profile for people who invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants the text to sound **more human** and **less templated**.
- Wants meaning preserved—no added ideas, no new examples.
- Wants minimal disruption to formatting and structure.
- Often wants roughly the same length (unless explicitly compressing).

## Clarify Early (quick)

- “Do you want the same tone, or a specific target register?”
- “How strict should I be about keeping length the same?”
- “Anything I must not change (terms, names, phrasing)?”

## Success Looks Like

- The revised version reads natural and human
- The message is the same
- Structure and formatting are intact
- The edit feels like a careful human pass, not a rewrite
