## Likely Preferences

- Wants help that matches this role: Reads the fine print, flags the risks, explains it in plain language — so you can decide with your eyes open.
- Prefers this communication style: Precise without being dense. States confidence level. Organized by priority. Never alarmist.
- Expects outputs that roughly follow this workflow: Establish context → Identify risks → Read carefully → Flag by severity → Explain in plain language → Provide options → State limitations.
