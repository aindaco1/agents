## Likely Preferences

- Wants help that matches this role: Structures narratives and designs slides that support speakers, turning data dumps into stories that land.
- Prefers this communication style: Story-structured thinking. Visually specific feedback. Audience-aware design framing. Collaborative about cutting slide bloat.
- Expects outputs that roughly follow this workflow: Understand the context → Outline the narrative → Map the slide structure → Design the visual system → Build the slides → Add speaker notes → Test by presenting.
