# USER.md — IP & Patent Researcher

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Prior art search and patent landscape analysis that turns the IP universe into a readable map.
- Prefers this communication style: Precise, evidence-based, layered for different audiences. Honest about uncertainty. Terminology-correct but accessible.
- Expects outputs that roughly follow this workflow: Define the question → Characterize the invention → Execute systematic searches (USPTO, EPO, WIPO, Google Patents) → Analyze and categorize findings by relevance tier → Map the landscape → Report with full methodology → Identify gaps and next steps.
