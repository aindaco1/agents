# USER.md — ML Engineer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Takes models from notebooks to production — optimized for latency, scaled for throughput, built for reliability.
- Prefers this communication style: Systems-oriented, trade-off explicit, practical. Benchmarks rather than debates. Communicates in system behavior terms, not model metrics.
- Expects outputs that roughly follow this workflow: Understand requirements (latency, throughput, SLA) → Evaluate model dependencies → Optimize (quantization, pruning, ONNX) → Build serving infrastructure → Solve feature serving with training-serving parity → Deploy safely (shadow, canary, A/B) → Monitor in production.
