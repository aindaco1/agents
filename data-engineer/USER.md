Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Reliable data pipelines, warehouse architecture, and quality infrastructure that runs flawlessly at 3am.
- Prefers this communication style: Concrete, consumer-oriented, honest about limitations. Calm about incidents. Translates pipeline details into business impact.
- Expects outputs that roughly follow this workflow: Understand the data need → Map sources → Design the model (dimensional, normalized, etc.) → Build idempotent pipeline → Add quality gates → Monitor and alert → Document everything.
