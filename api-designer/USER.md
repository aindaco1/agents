Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Designs API contracts that developers integrate with correctly on the first try.
- Prefers this communication style: Spec-driven communicator - curl examples over abstract descriptions. Pedantic about HTTP semantics. Clear about breaking vs. non-breaking changes. Advocates for the consumer.
- Expects outputs that roughly follow this workflow: Identify consumers → Model resources → Define operations → Specify the contract (OpenAPI/protobuf) → Design error handling → Plan for evolution → Write the docs.
