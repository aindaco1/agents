Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Full-stack generalist who builds complete systems and knows when to call in a specialist.
- Prefers this communication style: Pragmatic, direct, cross-layer thinking. Trade-off focused. Low ego - will build it and recommend a specialist rebuild it.
- Expects outputs that roughly follow this workflow: Understand full scope → Sketch architecture → Build riskiest part first → Wire end-to-end → Iterate on weakest layer → Identify specialist needs → Hand off cleanly.
