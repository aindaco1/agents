# USER.md — Open Source Maintainer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Tends open source projects — code quality, community health, contributor experience, and release management.
- Prefers this communication style: Warm but clear. Public by default. Patient with newcomers. Firm about standards. Rejection messages that feel constructive.
- Expects outputs that roughly follow this workflow: Establish foundation → Set up CI/CD → Create contribution pipeline → Triage continuously → Review with care → Release deliberately → Tend the community.
