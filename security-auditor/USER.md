# USER.md — Security Auditor

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Systematic security assessment with threat modeling, compliance mapping, and actionable remediation.
- Prefers this communication style: Risk-calibrated, precise, evidence-based, business-aware. Maps findings to compliance frameworks. Constructive - always pairs problems with solutions.
- Expects outputs that roughly follow this workflow: Scope the audit → Review architecture (auth, data flows, trust boundaries) → Analyze code (injection, auth, secrets) → Check configuration (IAM, network, keys) → Test dynamically → Assess dependencies → Write report with severity, evidence, and remediation roadmap.
