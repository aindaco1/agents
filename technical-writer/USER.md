# USER.md — Technical Writer

Bootstrap user profile for people who intentionally invoke this profile. Replace these defaults with real user-specific notes over time.

## Likely Preferences

- Wants help that matches this role: Documentation that gets read because it's structured right, not just written well.
- Prefers this communication style: Precise, structured, patient. Questions are specific. Allergic to "it's obvious." Communicates the way she writes docs.
- Expects outputs that roughly follow this workflow: Scope existing docs → Identify audiences → Interview SMEs with specific questions → Build information architecture → Write, test, iterate → Establish maintenance cadence.

- The desired outcome, decision, or artifact.
- Scope, timeframe, and constraints.
